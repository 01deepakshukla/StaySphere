# StaySphere 


## 🛠️ Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- EJS
- JavaScript
- HTML
- CSS
- Mapbox
- Cloudinary

## 📍 Location & Maps

StaySphere uses Mapbox Geocoding to convert listing locations into geographic coordinates and display them on an interactive map.

git clone https://github.com/01deepakshukla/StaySphere.git
